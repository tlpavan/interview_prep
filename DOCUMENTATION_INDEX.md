## Key Concepts Explained

### Multi-Agent Architecture
**Documents**: [MULTI_AGENT_ARCHITECTURE.md](MULTI_AGENT_ARCHITECTURE.md), [ARCHITECTURE.md](ARCHITECTURE.md)

The system uses 4 specialized autonomous agents:
1. **Interview Engine Agent** - Evaluates responses
2. **Question Generator Agent** - Creates questions
3. **Resume Analyzer Agent** - Analyzes resumes
4. **Career Path Agent** - Generates roadmaps

### Scoring System
**Documents**: [README.md](README.md), [MULTI_AGENT_ARCHITECTURE.md](MULTI_AGENT_ARCHITECTURE.md)

Four dimensions scored 0-100:
- Confidence
- Vocabulary
- Technical
- Communication

### Adaptive Learning
**Documents**: [MULTI_AGENT_ARCHITECTURE.md](MULTI_AGENT_ARCHITECTURE.md), [ARCHITECTURE.md](ARCHITECTURE.md)

System adapts based on:
- Performance history
- Difficulty level
- Domain expertise
- Learning pace

### Continuous Feedback Loop
**Documents**: [MULTI_AGENT_ARCHITECTURE.md](MULTI_AGENT_ARCHITECTURE.md), [README.md](README.md)

Sessions → Evaluation → Feedback → Updated Learning Path → Next Session

## API Endpoints Summary

### Interview Module
- `POST /api/interview/start` - Start interview
- `POST /api/interview/extract-name` - Extract name
- `POST /api/interview/next-question` - Generate question
- `GET /api/interview/voice-config` - Get voice config
- `GET /api/interview/recent` - Get recent sessions
- `GET /api/interview/profile-summary` - Get scores
- `GET /api/interview/gemini-health` - Check health

### Resume Module
- `POST /api/resume/analyze` - Analyze resume

### Career Module
- `POST /api/career/path` - Generate career path

**Full Details**: [API_DOCUMENTATION.md](API_DOCUMENTATION.md)
