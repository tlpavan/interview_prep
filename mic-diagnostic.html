🔧 Troubleshooting Guide

If no audio level is detected:

  1. Check microphone volume: Go to Windows Sound Settings and ensure microphone volume is above 50% and not muted
  2. Select correct device: Use the dropdown above to select your microphone
  3. Close other apps: Zoom, Teams, Discord, etc. might be using the mic
  4. Refresh page: After selecting device, refresh and try again
  5. Check browser permissions: Click the lock icon in address bar and ensure microphone is allowed
  6. Try different browser: Chrome or Edge work best

If audio level detected but speech fails:

  1. Check internet: Speech recognition requires internet connection
  2. Speak clearly: Speak at normal pace, not too fast or slow
  3. Reduce noise: Move to quieter environment
  4. Try text fallback: Use type input instead of voice
  5. Check API keys: Ensure Gemini API key is configured

Browser-specific notes:

  • Chrome/Edge: Best support, recommended
  • Firefox: Good support but may need重启
  • Safari: Limited Web Speech API support
  • Incognito/Private: Some features may be blocked
